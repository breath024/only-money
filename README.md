## 🚀 시작하기

### 그냥 열기 (제일 빠름)
1. `index.html` 더블클릭 → 브라우저에서 열림
2. 첫 방문이면 온보딩 위저드가 4단계로 안내
3. (선택) `⚙️` 클릭 → AI 키 입력하면 AI 분석가 활성화

### 로컬 서버로 실행 (권장 — RSS·F&G·번역 API 안정성 ↑)
```bash
# 폴더 안에서 (Python 3 필요)
python -m http.server 8000
# 또는 Node
npx serve

# 그 후 브라우저에서:
# http://localhost:8000
```

### 앱으로 설치 (PWA)
1. **로컬 서버**로 실행 중 상태에서 (`file://` 에선 안 됨)
2. Chrome/Edge 주소창 우측 `⊕` 아이콘 → "설치"
3. 데스크탑/홈 화면에 앱 아이콘 생성 → 독립 창으로 실행

## 🔒 프라이버시

**모든 데이터는 본인 브라우저에만 저장됩니다** (localStorage).

| 외부 서버 호출 | 무엇 | 누가 |
|---|---|---|
| `api.anthropic.com` | AI 분석가 호출 | 본인 API 키, 직접 호출 |
| `s3.tradingview.com` | 차트·티커·히트맵 위젯 | TradingView 임베드 |
| `api.allorigins.win`, `corsproxy.io` | RSS·F&G 프록시 (CORS 우회) | 공개 뉴스만 |
| `api.mymemory.translated.net` | 뉴스 한국어 번역 | 헤드라인만 |
| `translate.googleapis.com` | 번역 fallback | 헤드라인만 |
| `logo.clearbit.com` | 종목 로고 | 도메인만 |

**추적·분석 도구·광고 일체 없음.** 소스를 직접 읽고 확인 가능 (5,800줄 단일 HTML 파일).

## 💾 데이터 백업

브라우저 캐시 삭제·기기 변경 시 데이터 손실 방지를 위해 **정기 백업 권장**:

1. 도구 패널 → 💾 데이터 탭 → "전체 데이터 백업 다운로드"
2. 받은 JSON 파일을 클라우드 (Dropbox/iCloud/Google Drive)에 보관
3. 복원: 같은 화면 → "백업 파일에서 복원"

## 🤖 AI 분석가 6명 활용 가이드

분석은 본인의 Anthropic API 키로 직접 호출됩니다 (서버 경유 없음).

1. [console.anthropic.com](https://console.anthropic.com/settings/keys)에서 API 키 발급
2. 결제 등록 (소액 충전, 한도 설정 가능)
3. 대시보드에서 `⚙️ API 키` 클릭 → 키 입력
4. `🚀 분석 실행` 또는 `a` 키

| 분석가 | 관점 |
|---|---|
| 🐂 강세 | 매수 기회·상승 동력 발굴 |
| 🐻 약세 | 리스크·하락 가능성 강조 |
| 🌐 매크로 | Fed·금리·환율·지정학 |
| 📊 기술 | 모멘텀·심리·변동성 |
| 🧮 퀀트 | 밸류에이션·breadth·상관 |
| 🧠 종합 | 위 5명 통합 + 오늘의 액션 |

**비용**: Sonnet 4.6 기준 분석 1회 약 $0.03~0.05 (프롬프트 캐싱 적용).
**모델 변경**: 설정 → AI 모델에서 Haiku(저렴) 또는 Opus(최고품질) 선택 가능.

## 🛠 기술 스택

- **Vanilla HTML/CSS/JS** — 빌드 없음, 의존성 없음
- **TradingView Widgets** — 차트·티커·히트맵·스크리너
- **Claude Sonnet 4.6 API** — AI 분석 (옵션)
- **RSS Feeds + CORS Proxy** — 뉴스 (allorigins/corsproxy/codetabs 3단 폴백)
- **MyMemory + Google Translate** — 번역 (caches in localStorage)
- **CNN F&G + alternative.me F&G** — 시장 심리
- **PWA** — manifest + service worker로 설치 가능

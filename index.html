🏠 Ollama CORS 설정 가이드

Ollama는 기본적으로 같은 컴퓨터에서만 접근 가능합니다. 브라우저(특히 file://)에서 호출하려면 OLLAMA_ORIGINS 환경변수를 설정해야 합니다.

🪟 Windows (PowerShell, 영구 설정)

[Environment]::SetEnvironmentVariable("OLLAMA_ORIGINS", "*", "User")

실행 후 Ollama 재시작 (트레이 아이콘 우클릭 → Quit → 다시 실행).

🍎 macOS / Linux (영구 설정)

launchctl setenv OLLAMA_ORIGINS "*" # 또는 ~/.zshrc 에 추가: export OLLAMA_ORIGINS="*"

실행 후 Ollama 재시작.

⚡ 일회용 (현재 세션만)

# Windows PowerShell $env:OLLAMA_ORIGINS="*"; ollama serve # macOS/Linux OLLAMA_ORIGINS="*" ollama serve

🔒 보안 권장

"*"는 모든 origin 허용으로 편하지만, 보안 신경 쓰면 특정 origin만 허용 (예: "null,http://localhost:8000"). 파일을 그냥 열면 (file://) origin이 null이므로 null이 포함돼야 합니다.
